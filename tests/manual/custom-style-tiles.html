地址格式与调试说明

支持包含 {z}、{x}、{y} 的 HTTP/HTTPS 地址，包括查询参数；行列顺序直接写在地址中，例如 /{z}/{y}/{x}.jpg。适用于 Web Mercator 栅格瓦片，切换 XYZ/TMS 不会转换投影。

瓦片尺寸为 256 时，地图缩放与瓦片级别通常相差一级。请按服务的实际覆盖范围调整最小/最大瓦片级别和中心位置。

浏览器直接访问瓦片服务，需要服务允许跨域；HTTPS 页面需使用 HTTPS 瓦片。分享链接包含瓦片地址和查询参数，发送前请确认其中的 Token 可以分享。
