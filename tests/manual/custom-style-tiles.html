粘贴一张具体瓦片地址即可自动生成模板并定位，也可输入模板手动配置。支持预览、响应检测和分享。

地址格式与调试说明

具体地址支持 /z/x/y.png、.jpg、.webp 等或 z/x/y、TileMatrix/TileCol/TileRow 查询参数（数字级别）。点击“加载图层”自动生成模板、填写中心与缩放，并检测该瓦片。其他查询参数原样保留。

数字路径默认按 z/x/y 解析；若服务为 z/y/x，请先选择对应路径顺序。查询参数按名称识别，已有模板按占位符识别。TMS 需先选择编号规则。自动定位假设标准 Web Mercator 网格，不能自动识别投影或自定义 WMTS 矩阵。

瓦片尺寸为 256 时，地图缩放与瓦片级别通常相差一级。单张瓦片无法推断服务的完整级别范围，因此自动定位暂将最小/最大瓦片级别都设为该瓦片级别；需要时可手动扩大范围。

浏览器直接访问瓦片服务，需要服务允许跨域；HTTPS 页面需使用 HTTPS 瓦片。分享链接包含瓦片地址和查询参数，发送前请确认其中的 Token 可以分享。
